# September 8 removal release

Instrument isolation has been removed at the user's request. The song screen no longer offers preparation or mix playback. Its API routes, dedicated queue/worker, Demucs runtime, model setup, tests and feature documentation have been deleted. Live uses the existing Spotify timing and loop controls again. The practice redesign and deferred metronome audio initialization remain.

On app launch, only the retired `Library/Caches/Isolation` directory is deleted. Normal song caches and saved practice takes are outside that directory. The dedicated hosted worker was stopped and destroyed before release; the deployment configuration now contains only the API and song-analysis worker. Server job metadata and generated mixes are removed after the API deployment so old builds cannot recreate them.

Validation: 375 backend tests passed, 17 existing expected failures; 1,201 song/playback checks passed; practice take, report, feedback and metronome lifecycle suites passed. Debug simulator and unsigned Release iPhone builds succeeded. Simulator verification confirmed the song toolbar has no isolation entry, old mixes are deleted at launch, and an unrelated cache sentinel survives. The initial sandboxed backend run could not open loopback HTTP fixtures or write model caches; the complete suite passed when rerun with those permissions.

Phone users need the next TestFlight build to remove the old screen. An older installed build retains its UI but the retired server routes are no longer available after deployment.
